# 每月結餘小幫手

這是一個不需要後端的本機網頁 MVP，對應 `每月結餘小幫手_待開發流程執行文件.md`。

## 開始使用

直接用瀏覽器開啟 `index.html` 即可。建議用桌面版 Chrome、Edge 或 Firefox。

1. 選擇月份，填入薪資、兼職收入與房租。
2. 點選「匯入帳單 PDF／截圖」，選擇元大或台北富邦。
3. 若帳單已顯示在螢幕上，按「直接擷取目前畫面」，在瀏覽器畫面選擇器選取帳單所在的視窗或螢幕，再拖曳框選帳單區域並按「裁切並辨識」；也可以改選 PDF 或 PNG／JPG／WEBP 截圖檔案。
4. 裁切後只會將框選區域送入瀏覽器本機 OCR；在預覽確認後匯入。若 PDF／OCR 無法解析，可手動填寫本期應繳金額建立待確認資料。
4. 在消費明細中修正分類，系統會即時更新月度與年度總覽。
5. 使用「匯出本機備份」保存 JSON；備份檔不要上傳至 GitHub。

「載入虛構測試資料」可快速查看富邦 4,211 元對帳案例，以及元大仍待確認本期應繳總額的情境。

## 資料與隱私

- 月度資料保存於瀏覽器的 `localStorage`，不會自動傳到伺服器。
- PDF 與帳單截圖解析都在瀏覽器中進行，不會上傳檔案。
- 直接擷取畫面只會在使用者選取的視窗或螢幕上擷取一張本機圖片，完成後立即停止畫面擷取串流。
- PDF.js 與 Tesseract.js 會從 CDN 載入；若當下離線，仍可使用圖片預覽、手動金額、手動新增、虛構測試資料與備份功能。
- 若 OCR 沒有讀到金額或交易，系統不會寫入空白帳單，會要求重新框選或手動補上本期應繳金額。
- 真實帳單不得放入 GitHub。GitHub 只應存程式碼、文件與虛構測試資料。

## 目前限制

- 元大與富邦的實際 PDF 版型尚未用真實脫敏樣本完整驗證。
- 掃描圖片型 PDF 尚未支援 OCR。
- 瀏覽器本機資料會依瀏覽器使用者設定保存；清除網站資料可能一併清除內容，因此請定期匯出備份。
